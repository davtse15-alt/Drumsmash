# Drum Smash

A gentle, colourful tap and keyboard drum toy for toddlers and little drummers.

## Features
- **Drum Party mode:** Tap any drum on the interactive toy drum kit (kick, snare, hi-hat, floor tom, crash cymbal) or tap anywhere / press any key for synthesized Web Audio drum sounds and floating vector bursts. Hold down for a drum roll.
- **Numbers & Emoji mode:** Tap colourful counting pads (`1`–`5`) or press any key for gentle marimba notes and cheerful surprises.
- **Parent Controls:** Press and hold the top-left corner for 1.5 seconds (or focus it with `Tab` and press `Enter`/`Space`) to switch modes, mute sound, or reset the smash counter. Press `Escape` to close.
- **Gentle by design:** Warm pastel palette, no harsh flashing, one sound at a time, and `prefers-reduced-motion` support.

## Running locally
Open `index.html` in any modern browser, or serve the folder with any static file server:

```bash
python3 -m http.server 8080
```
